# Codeburn

Use Codeburn for token-usage monitoring and waste detection.

Use it when:
- a session is getting long or expensive
- tool output is noisy
- the agent is looping, over-explaining, or re-reading too much
- you want to measure where tokens are being burned before changing workflow

What it is for:
- measurement, not compression
- spotting waste in prompts, outputs, and iteration patterns
- helping decide when to switch to shorter output styles or leaner tools

Working rule:
- use Codeburn to detect waste, then reduce it with RTK, Headroom, Caveman, Ponytail, or tighter task scope
